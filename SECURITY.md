# Security Policy

## Supported Versions

Security reports are accepted for the latest maintained version of the C++ Binary Search Tree project.

## Reporting a Vulnerability

If you discover a potential security vulnerability, please report it privately through GitHub's vulnerability reporting feature.

1. Navigate to the repository's Security section.
2. Open Security Advisories.
3. Select "Report a vulnerability."
4. Provide a description of the vulnerability, steps to reproduce it, the affected version, and its potential impact.
5. Submit the report privately.

Please do not publicly disclose sensitive vulnerability details through GitHub Issues.

The project aims to acknowledge security vulnerability reports within 14 days of receipt.

## Reporting Non-Security Issues

For general bugs, feature requests, or improvements, please use the repository's GitHub Issues section.
