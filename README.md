## Overview

This project is a C++20 console application that demonstrates how a **binary search tree (BST)** organizes integer values for structured storage and traversal. It inserts integers according to BST ordering and displays the resulting tree using three traversal methods. The project is intended for learning and demonstrating a fundamental data structure; it is not a general-purpose database or interactive search tool.

## Features

- Insert integers according to binary search tree ordering.
- Track duplicate values using a frequency field rather than creating additional nodes.
- Print **in-order**, **pre-order**, and **post-order** traversals.
- Reject non-integer input and require a positive number of input elements.
- Release allocated tree nodes when the BST object is destroyed.

**Current scope:** The program demonstrates insertion and traversal. It does **not** provide interactive searching or deletion of individual values. Duplicate frequencies are tracked internally but are not displayed in traversal output.

## Input and Output Interface

This is a **console program**. It accepts values from standard input and prints results to standard output; it does not expose a web API or graphical interface.

### Input

1. Enter a **positive integer** specifying how many values will be inserted.
2. Enter that many **integer values** for insertion into the BST.
3. Non-integer input is rejected. The initial count must be greater than zero.

For example, these input values represent five insertions:

```text
5
8
3
10
1
6
```

### Output

The program displays the resulting BST in three traversal orders:

| Traversal | Meaning | Values for the example above |
| --- | --- | --- |
| In-order | Left subtree, node, right subtree | `1 3 6 8 10` |
| Pre-order | Node, left subtree, right subtree | `8 3 1 6 10` |
| Post-order | Left subtree, right subtree, node | `1 6 3 10 8` |

The sequences illustrate the expected traversal order; the exact printed labels and spacing may differ. For an in-order traversal, the unique node values appear in ascending order. A repeated inserted value increments its node's frequency field; the traversal display does not report those frequency counts.
